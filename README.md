#Hosptial Appointment Operation

📌 Project Overview

This project uses SQL Server to analyze hospital appointments, appointment statuses, doctor workloads, and patient no-show patterns. It demonstrates how SQL can support healthcare operations and improve appointment management.

🛠️ Tools Used

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- T-SQL

🎯 Key Analysis

- Analyze appointment status and trends.
- Identify doctor workloads.
- Track patient no-show rates.
- Summarize appointment data by department.
- Perform data quality checks.

🧠 SQL Skills

- Joins and subqueries
- GROUP BY and aggregate functions
- CTEs and window functions
- Views and stored procedures
- Data validation

💼 Business Value

Helps demonstrate how healthcare teams can monitor appointment activity, understand no-show patterns, and support better scheduling decisions.
